# kr1-start-E — начален проект, Рецепти

Форма `MainForm` с всички контроли, поставени и кръстени; без нито един ред логика.
Ако дизайнерът откаже да отвори формата, кодът в `initComponents()` е пълен и
проектът се компилира и стартира; събитията тогава се закачат от кода с
`addActionListener(e -> …)`.
